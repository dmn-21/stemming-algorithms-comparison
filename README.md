# Stemming Algorithms Comparison

Comparative analysis of **Snowball (Porter2)** and **Lancaster (Paice–Husk)** stemming algorithms for sentiment classification using NLP and Machine Learning.

### Dataset
[IMDb Dataset of 50K Movie Reviews – Kaggle](https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews)

### Technologies
Python, Pandas, NLTK, Scikit-learn, TF-IDF, Logistic Regression, JupyterLab.

### Results

| Model | Accuracy | F1-score |
|---|---:|---:|
| Baseline | 90.85% | 90.85% |
| Snowball | **90.90%** | **90.90%** |
| Lancaster | 90.64% | 90.64% |

**Conclusion:** Snowball achieved the highest classification performance, while Lancaster provided greater vocabulary reduction.
